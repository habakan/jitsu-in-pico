# Pico 2 H ケース Rev C — 調整用試作

外形 **63.4 × 43.4 × 42.3 mm**（ボタンを含む高さ43.3 mm）。キャリア基板は58 × 38 mmです。前面に液晶と操作ボタン、背面にカメラを置き、Picoはキャリア基板の裏面へ挿します。面積を小さくした代わりに部品を重ねたため、Rev Bの30.4 mmより厚くなっています。ユーザー了承のもと、未計測箇所は仮寸法で作成しています。

## Bambu Studioで印刷するファイル

| ファイル | 内容 | 印刷方向 |
|---|---|---|
| [bambu_plate_01_base.3mf](bambu_plate_01_base.3mf) | 背面ケース1個（カメラ窓付き） | 外側底面がベッド |
| [bambu_plate_02_front.3mf](bambu_plate_02_front.3mf) | 前カバー1個 | 外側の画面側がベッド |
| [bambu_plate_03_small_parts.3mf](bambu_plate_03_small_parts.3mf) | カメラ裏押さえ1個、押し子2個 | 裏押さえは平置き、押し子は頭がベッド |

3MFは**mm単位の形状のみ**を含みます。3ファイルをそれぞれ別の印刷として開きます。プリンター・素材設定、サポート、G-codeは含みません。小物3個は間隔を空けて配置済みです。

プリンター本体のUSB/SDから印刷する場合、本体の一覧に出るのはスライス済みの`.gcode.3mf`だけです。この3MFをそのままコピーしても表示されません。

1. Bambu Studioで実機の機種・ノズル径を選択します。今回の想定はX2Dです。
2. 各3MFを開きます。選択肢が出た場合は形状の読み込みを選びます。
3. 倍率100%のままプレート中央に配置します。背面ケースが63.4 × 43.4 × 39.9 mmであることを確認します。
4. 素材未指定のため、最初の案はPLA・0.4 mmノズル・積層0.20 mm・壁4周・上下5層・インフィル20%です。温度とベッドは使用フィラメントのプリセットを使います。
5. 背面ケースのUSB穴上辺、押し子のつば下面はサポート対象です。プレビューで浮いた層がないか確認します。前カバーは固定柱が上向きです。外側ねじ座ぐりの橋渡しも確認してください。
6. プレートをスライスし、「プレートのスライスファイルをエクスポート」で`.gcode.3mf`を保存します。USB/SDへはこのファイルをコピーします。Bambu Studioの「印刷」から直接送ってもかまいません。
7. まず空のケースと押し子を仮組みしてから、部品を取り付けます。

X2Dの公式造形範囲（主ノズル256 × 256 × 260 mm）に収まる寸法です。[Bambu Lab公式仕様](https://blog.bambulab.com/xcellence-made-simple-bambu-lab-presents-the-x2d/)

## どこに入るか

| 部品 | 固定・接続 |
|---|---|
| LCD M154-240240-RGB | 前面左。4つの基板穴を前カバーの柱へねじ留め。キャリア表面のJ3へ8芯ハーネス |
| 操作スイッチ2個 | キャリア表面の右端。前カバーの穴に通した押し子で操作 |
| キャリア基板 | 58 × 38 mm、四隅1 mm面取り。背面ケースの4本の柱と前カバーの柱で挟み、ケースねじで共締め |
| Pico 2 H | キャリア**裏面**の1×20ソケット2本に挿入。部品面は背面側。USBは左側の16 × 9.6 mm開口へ |
| カメラ B0070 | 背面ケースの内側。レンズを背面のØ18 mm窓へ向け、四隅の受けと裏押さえで挟んで4本のねじで固定。キャリア裏面のJ4へ20芯ハーネス。カメラ側は2×10ピンソケット（高さ8.5 mm）に短い線を付けたもの |

Picoを裏面に挿すため、KiCadではJ1/J2をB面に配置し、ピン配列が左右反転することに注意します。BOOTSELはキャリア基板を外して操作します。ブレッドボードをそのまま収納する設計ではなく、キャリア基板へ移設する前提です。

## ねじ・組立

ねじは樹脂へねじ込む試作想定です。長さは頭を除く値で、下穴径とねじ形状は試し刷りで合わせます。

| 用途 | 候補 | 数 | モデルの下穴 |
|---|---|---|---|
| ケース開閉・キャリア固定 | 呼び径2.5 × 25 mm、樹脂用タッピングねじ | 4 | Ø2.0、深さ10 mm（背面ケース側） |
| LCD固定 | M1.6 × 5 mm | 4 | Ø1.3、盲穴 |
| カメラ裏押さえ | M2 × 8 mm | 4 | Ø1.6、盲穴 |

LCD穴はØ2.0 mmなので、M2.5は使いません。LCD固定ねじは裏面から挿します。小ねじを樹脂へ直接使う箇所は、必要に応じて下穴の径・深さを調整してください。強く締め込むと柱が割れるため、基板が動かなくなる程度で止めます。

1. キャリア基板の表面にJ3・J5・スイッチ、裏面にPico用ソケットとJ4を取り付け、配線を完成させます。表面のはんだ側リードはPicoのヘッダ側へ出るため、短く切りそろえます。
2. カメラを背面ケースの四隅の受けへ置き、裏押さえをねじ留めします。カメラのハーネスを先に挿しておきます。
3. キャリア裏面へPicoを挿し、カメラのハーネスをJ4へつないでから、キャリアを背面ケースの4本の柱へ載せます。
4. 前カバーを裏返し、押し子2個を穴へ入れます。押し子は完成時にスイッチとの隙間0.2 mmを想定しています。
5. LCDを4本の柱へ固定します。ガラスと前カバーは0.3 mm離す想定です。LCDのハーネスをJ3へつなぎます。
6. 前カバーを載せ、4本のねじで前カバー・キャリア・背面ケースをまとめて固定します。
7. USBケーブルが挿せること、ボタンが戻ること、配線を挟まないことを確認します。

## 仮寸法の調整

[case_dimensions.json](case_dimensions.json)を編集して再生成します。XY座標はキャリア基板（KiCad）の座標で、ケース座標は各2.7 mm足した値です。高さ方向は背面からカメラ、Pico、キャリア、LCDの順に積み上げて自動計算します。「調整可能」は主にCAD寸法の変更・再印刷を意味し、完成品にスライド調整機構はありません。

| パラメータ | 現在値 | 実物で確認する箇所 |
|---|---|---|
| `camera.lens_height` | 3 mm（写真から2〜3 mmと推定） | **基板表面から**レンズ先端まで。裏面から測った値なら基板厚を引く |
| `camera.pcb_thickness` | 1.6 mm | カメラ基板厚 |
| `camera.lens_offset` | [15.25, 15.25] mm | 基板左上からレンズ中心 |
| `camera.rear_connector_depth` | 11 mm | 基板裏面から接続済みヘッダ・コネクタの最下面。2×10ピンソケットの短いハーネス前提。ジャンパーワイヤのメス端子は約16.5 mm＋曲げ代が要り収まらない |
| `lcd.active_origin` | [7.11, 2.14] mm | 横向き基板の左上から表示域左上。図面の向きは実物照合待ち |
| `lcd.rear_connector_depth` | 11.3 mm | LCD裏側の接続済みコネクタ |
| `pico.socket_height` / `header_height` | 8.5 / 2.5 mm | キャリア裏面からPicoまで合計11 mm |
| `pico.component_gap` | 2 mm | カメラ裏押さえとPico部品面の間隔 |
| `buttons.switch_height` | 7.3 mm | キャップを外したスイッチ上端。実物照合待ち |
| `case.fit_clearance` | 片側0.3 mm | ケースのはめ合い |

レンズ高さ・コネクタ深さを変更すると、ケースの厚みと各柱の高さも変わります。大きく変更した場合は周辺部品との干渉チェックが失敗することがあります。ヘッダの向き・XY位置、取付面、ねじ径は必要に応じて`build_case_stl.py`で変更します。ケース全体の大きな変更には配線コネクタ等の固定座標も見直してください。

カメラは四隅1.2 mm角の受けに載り、裏押さえは左右の辺1.2 mm幅を押さえます。ヘッダは上辺にあると仮定し、上辺は押さえません。その場所に部品がないか確認します。ハーネスの曲げ余裕・はんだ面・光学的な視野角はモデルに含まれていません。Ø18 mmのカメラ窓は仮値です。

## 再生成

Python 3.11の仮想環境で、リポジトリ直下から実行します。

```sh
uv venv -p 3.11 /tmp/pico-case-venv
VIRTUAL_ENV=/tmp/pico-case-venv uv pip install -r hardware/kicad/pico2h-carrier/3dprint/requirements.txt
/tmp/pico-case-venv/bin/python hardware/kicad/pico2h-carrier/3dprint/build_case_stl.py
```

STL、3MF、OpenSCAD、GLB、KiCad参照用VRML、画像、HTML、検査レポートを出力します。OpenSCADは生成結果で、寸法変更はJSON/Pythonが正本です。`part`に`base`、`lid`、`camera_retainer`、`button_1`、`button_2`を指定すると印刷向きで表示します。

KiCadの機械配置を更新する場合だけ、次を別途実行します。電気フットプリント・配線があるPCBへの自動上書きは拒否します。

```sh
/tmp/pico-case-venv/bin/python hardware/kicad/pico2h-carrier/3dprint/update_mechanical_layout.py
```

日本語画像にはmacOSのHiragino Sans GBを使用します。他のOSでは`render_case.py`の`FONT`を日本語フォントへ変更してください。
