# Pico 2 H ケース試作

KiCadの92×82 mm仮基板に合わせた、前面カバーと背面トレイのSTLです。組立時の外形は約100×90×34.8 mmです。STLはミリメートル寸法で出力し、FDMプリンターで印刷する向きに置いてあります。

## ファイル

- `pico2h_case_base.stl`: 背面トレイ。底面をベッドに置いて印刷します。
- `pico2h_case_front.stl`: 前面カバー。画面側の平面をベッドに置いて印刷します。
- `pico2h_case.scad`: OpenSCAD用の寸法調整可能な元データ。`part` を `base` または `front` にしてSTLを書き出せます。
- `build_case_stl.py`: Python標準ライブラリだけでSTLを再生成するスクリプト。

## 仮寸法と前提

- 外形は100×90 mm。基板はケース内で中央に置き、四隅の受け台に載せます。
- 液晶の有効表示域はデータシート記載の27.72 mm角を基準に、28.4 mm角窓にしています。[データシート](https://akizukidenshi.com/goodsaffix/M154-240240-RGB-8.pdf)
- 前面カバーにはカメラ用15 mm角窓と、ボタン用6.8 mm角穴を設けています。
- PicoのUSB端子向けに左側面へ13×7.5 mmの開口を設けています。
- 前後パーツはM2.5×30 mmセルフタッピングねじ4本で固定する想定です。基板に固定穴がないため、基板は四隅の受け台に載せ、薄い両面テープで仮固定します。
- ケースとトレイのはめ合いは片側0.25 mmの隙間です。プリンターの収縮や初層の膨らみで入らない場合は、`fit_clearance` を増やして再出力してください。

## 印刷前に確認

KiCad基板の配置、カメラレンズ中心、PicoのUSB位置は暫定値です。LCDデータシート上の有効表示域を基板の仮配置へ重ね、カメラは30.5 mm角モジュールの中央にレンズがある前提で窓を置いています。実物をノギスで測り、STLをスライサーに読み込んで開口位置を確認してから印刷してください。まずPLAで低速の試し刷りを行い、基板と部品を入れずに上下パーツのはめ合いを確かめます。

カメラ穴と画面窓の正確な位置、USB端子と開口の高さ、ケース内の部品高さはまだ実測していません。電子部品を入れて通電する前に、ケーブルが引っ掛からず、基板や部品に圧力がかからないことを確認してください。
